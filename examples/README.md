This folder holds real sample outputs generated with Cutaway presets. Each file is named ``<preset-id>_<n>.<ext>`` so you can see which preset produced it.

## Kawarimi samples

``kawarimi_<n>.mp4`` is a character swap: ``kawarimi_<n>_source.mp4`` is the
source clip as used (trimmed to the engine's cap) and
``kawarimi_<n>_character.png`` is the character swapped in. The source audio is
kept. All media was generated in Phaino with original characters; no real
people, no existing IP.

| File | Engine | Source | Character |
| --- | --- | --- | --- |
| kawarimi_1.mp4 | MiniMax H3 (kawarimi-h3) | 16:9 studio dance (Veo 3.1 Fast) | paper-craft origami samurai (Nano Banana 2.1) |
| kawarimi_2.mp4 | MiniMax H3 (kawarimi-h3) | 9:16 rooftop walk and wave (Veo 3.1 Fast) | knitted wool fox in a yellow raincoat (Nano Banana 2.1) |
| kawarimi_3.mp4 | Seedance 2.5 (kawarimi-seedance), candidate | 16:9 studio dance (Veo 3.1 Fast) | porcelain robot with orange seams (Nano Banana 2.1) |

Default prompt: "Replace the person in <Video 1> with the character from
<Picture 1>. Keep the motion, camera and background." for H3, the equivalent
prompt syntax for other engines.
