# Presets

A preset is a folder in this directory:

```
presets/<id>/
├── preset.json         # preset definition (schema below)
├── workflow.json       # ComfyUI UI-format graph (openable in the editor)
├── workflow_api.json   # API-format graph, generated by the export script
└── thumb.webp          # card thumbnail
```

`workflow.json` and `workflow_api.json` are generated, not hand-edited: they come from loading the source template into ComfyUI and calling `graphToPrompt()`. To preview one, drag `workflow.json` onto the ComfyUI canvas.

## preset.json

| Field | Meaning |
| --- | --- |
| `id` | Slug; must equal the folder name (`^[a-z0-9]+(-[a-z0-9]+)*$`) |
| `name` | Display name |
| `description` | One-line description |
| `category` | `camera` or `image`; decides which tool the preset appears in |
| `order` | Sort order inside the category |
| `chip` | Optional short spec shown on the card (e.g. `90°`) |
| `engine` | `workflow` (M7 adds `router`) |
| `model` | `{ id, label, license }`; license is `open` or `partner` |
| `source` | `{ template, modes? }`: the workflow_templates template name and optional top-level node `mode` overrides (e.g. bypassing one of two subgraphs) used at export time |
| `inputs` | File inputs. `{ key, type: "image", label, required, bind }` |
| `params` | User-facing params (see below) |
| `outputs` | Nodes that produce the result: `{ node, kind: "video" \| "image" }` |

Params (`params` array, discriminated by `type`):

- `text`: `{ key, label, default, placeholder?, template?, bind }`. With `template`, the written value is the template with `{key}` placeholders replaced by other param values (e.g. `{prompt} {style}`); without one the raw value is written. Unknown placeholders are a validation error.
- `seed`: `{ key, label, bind }`. Uses the caller's seed option unless the user overrides it.
- `choice`: `{ key, label, default, options, bind? }`. Each option is `{ value, label, set? }`; picking one writes `value` to `bind` (when present) and applies every `set` entry (`{ node, field, value }`). A choice with neither is only usable inside text templates. `default` must equal an option value.
- `int`: `{ key, label, default, min, max, bind }`; out-of-range values are rejected at bind time.

Every key across `inputs` + `params` must be unique.

## Binds

`bind` is `{ node, field }` where `node` is a node id in `workflow_api.json`. Subgraph internals are flattened: internal node `376` inside subgraph node `398` is bound as `398:376`. `field` is a widget input name that holds a **literal** value in `workflow_api.json`; if the value you need is a link (fed by a primitive), bind to the primitive node's `value` field instead.

Camera binds (from `video_ltx2_5_i2v`): `395.image` (first frame), `398:376.value` (prompt), `398:339.noise_seed`, `398:362.value` (seconds), `398:361.value` (fps), `403.aspect_ratio`, output `75` (SaveVideo).

FLUX binds (from `image_flux2_klein_text_to_image`): `76.value` (prompt), `75:73`/`77:86` `.noise_seed`, width/height primitives `75:68`/`75:69` or `77:84`/`77:85` `.value`, batch `75:66`/`77:83` `.batch_size`, outputs `9` (base) / `78` (distilled).

## Adding a preset

1. Copy an existing folder, rename it, edit `preset.json` (new `id`, copy, binds).
2. With a CPU-only ComfyUI running (`COMFYUI_URL`, default `http://127.0.0.1:8188`), run `pnpm --filter cutaway-studio export:workflows` to regenerate `workflow.json`/`workflow_api.json` for every preset.
3. Run `pnpm test` to validate the folder against the object_info snapshot.
